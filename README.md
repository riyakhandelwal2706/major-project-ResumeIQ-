# 📄 ResumeIQ : AI-Driven Resume Analysis and Skill Gap Detection using NLP

ResumeIQ is an AI-powered Resume Screening and Job Matching System built using Python, Streamlit, NLP, and Machine Learning techniques.

The system analyzes resumes against job descriptions using TF-IDF and Cosine Similarity to provide match scores, ATS compatibility analysis, skill gap detection, interview preparation support, and personalized resume improvement suggestions.


# 🚀 Features

## ✅ Resume Match Analysis
- Upload Resume in PDF format
- Compare with Job Description
- Generate Overall Match Score

## 📊 Section-wise Analysis
Analyze individual sections:
- Summary
- Experience
- Skills
- Education
- Projects

## 🔥 ATS Compatibility Checker
- ATS Score Calculation
- ATS-friendly suggestions
- Resume formatting analysis

## 📈 Skill Gap Analysis
- Matching Skills Detection
- Missing Skills Identification
- Recommended Skills to Learn

## ✨ Resume Improvement Suggestions
- Missing keyword recommendations
- Action verb suggestions
- Quantifiable achievement guidance

## 🤖 Job Recommendation System
Suggests roles like:
- Data Analyst
- Data Scientist
- ML Intern
- Frontend Developer
- Backend Developer

## 🎯 AI Interview Questions Generator
- Technical Questions
- HR Questions
- Problem-solving Questions
- Culture-fit Questions

## 🔐 Login & Authentication System
- Secure Login
- Signup Feature
- Full Report Access after Authentication

## 📉 Visualization Dashboard
- Section-wise score charts
- Match analysis graphs
- Data visualization
